# MigrApp - Planificación de Proyectos de Migración

MigrApp es una plataforma de planificación, seguimiento y control de proyectos de migración tecnológica.

## Estructura de Carpetas

El proyecto sigue una estructura Modelo-Vista-Controlador (MVC):

-   `index.html`: Punto de entrada de la aplicación.
-   `controllers/`: Contiene la lógica de la aplicación que maneja las interacciones del usuario.
-   `models/`: Define la estructura de los datos de la aplicación.
-   `views/`: Se encarga de la presentación de los datos al usuario.
    -   `css/`: Contiene los archivos de estilos.
